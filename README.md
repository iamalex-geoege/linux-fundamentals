# Linux Fundamentals and System Administration

## Project Overview
This project documents my practical learning and hands-on exercises in Linux fundamentals and basic system administration.

The exercises were completed using Kali Linux in an Oracle VirtualBox environment as part of my cybersecurity learning journey.

## Objectives
- Develop confidence using the Linux command line.
- Understand Linux filesystem navigation and management.
- Practise file and directory operations.
- Understand file permissions and process management.
- Explore basic network configuration and connectivity testing.
- Inspect listening ports and search security logs.

## Tools and Environment
- **Operating System:** Kali Linux
- **Virtualisation:** Oracle VirtualBox
- **Learning Platform:** TryHackMe – Linux Fundamentals Part 1

## Practical Exercises
The exercises covered:

1. Linux command-line navigation.
2. Creating, copying, moving and inspecting files and directories.
3. Managing file permissions.
4. Inspecting running processes.
5. Examining network interface configurations.
6. Performing basic network connectivity tests.
7. Inspecting listening ports.
8. Searching security logs for failed-login entries.
9. Reviewing available package updates.

## Skills Developed
- Linux command-line operations
- Filesystem management
- File permissions
- Process inspection
- Basic networking
- Security log analysis
- Linux system administration fundamentals

## Learning Outcomes
This project strengthened my understanding of Linux environments and developed practical skills relevant to cybersecurity, system administration and penetration testing.

## Disclaimer
All exercises were conducted in a personal virtual machine and authorised learning environment for educational purposes.
